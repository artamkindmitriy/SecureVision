# SecureVision — Корпоративный сайт компании 🌐

**SecureVision** — это полноценный адаптивный веб-сайт, созданный для реального коммерческого заказчика. Проект представляет собой современный корпоративный ресурс, который знакомит пользователей с услугами компании, её преимуществами и предоставляет удобные каналы для связи.

---

## 🛠️ Стек технологий:
* **Разметка:** HTML5 (семантическая верстка)
* **Стилизация:** CSS3 (Flexbox, Grid, адаптивные медиа-запросы)
* **Интерактивность:** JavaScript (ванильный JS для динамических элементов)

---
